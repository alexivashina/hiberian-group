## 1. Що це за проєкт

Це **статичний сайт** організації «Гібернійська група» (Hibernian Group).
Він зроблений на чистому **HTML + CSS**, без бекенду, без бази даних, без збірки (no build step).

- 🌐 **Домен:** https://hiberniangroup.org.ua
- 💻 **Хостинг:** GitHub Pages (безкоштовно)
- 📦 **Репозиторій:** https://github.com/alexivashina/hiberian-group
- 💰 Раніше сайт був на конструкторі OnePage ($20/міс). Тепер — безкоштовно на GitHub Pages.

**Як працює деплой:** будь-який `git push` у гілку `main` автоматично оновлює сайт за ~1 хвилину. Нічого збирати чи компілювати не треба.

## 4. Що встановити на компʼютер (ПЕРШИЙ РАЗ)

Якщо комп'ютер «чистий» (немає git, gh, Claude) — спочатку треба поставити кілька безкоштовних програм.
**Якщо ти Claude — ти можеш виконати ці команди в терміналі сам.**

Потрібні інструменти:
| Програма | Навіщо |
|----------|--------|
| **Git** | завантажувати й відправляти зміни в репозиторій |
| **GitHub CLI (`gh`)** | зручна авторизація в GitHub |
| **Node.js** | потрібен для Claude Code (якщо користуєтесь Claude Code) |
| **Claude Code** | сам AI-помічник у терміналі |

### 🍎 macOS

```bash
# 1. Homebrew (менеджер пакетів) — якщо ще немає:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. Git, GitHub CLI, Node.js:
brew install git gh node

# 3. Claude Code:
npm install -g @anthropic-ai/claude-code
```

### 🪟 Windows (у PowerShell)

```powershell
# 1. Git, GitHub CLI, Node.js:
winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id OpenJS.NodeJS.LTS -e

# 2. Закрий і знову відкрий PowerShell, потім Claude Code:
npm install -g @anthropic-ai/claude-code
```

> ℹ️ Офіційна інструкція зі встановлення Claude Code (якщо щось зміниться):
> https://docs.claude.com/claude-code

### Авторизація в GitHub (один раз)

```bash
gh auth login
```
Обери у підказках: **GitHub.com → HTTPS → Login with a web browser** — відкриється браузер, увійди у свій GitHub-акаунт.

### Підпис комітів (один раз)

```bash

git config --global user.email "твій@email.com"
```

## 6. Найчастіша задача — ДОДАТИ НОВИНУ

Новини живуть у секції `<!-- NEWS -->` у файлах `index.html` (укр) і `en.html` (англ).
Найновіша новина має бути **першою** (зверху) у блоці `<div class="cards" ...>`.

### Крок 1. Додати фото
1. Поклади зображення у папку `img/` (бажано стиснене, ширина ~1200–1400px, формат `.jpg`).
   Назви зрозуміло, напр. `news-forum-2026.jpg`.
2. На macOS стиснути можна так:
   ```bash
   sips -s format jpeg -Z 1400 -s formatOptions 82 вхідне.jpg --out img/news-forum-2026.jpg
   ```

### Крок 2. Вставити картку новини

**Шаблон (УКРАЇНСЬКА) — встав одразу після `<div class="cards" ...>` у `index.html`:**

```html
<article class="card">
  <div class="card-media"><img src="img/news-forum-2026.jpg" alt="Короткий опис фото"></div>
  <div class="card-body">
    <span class="badge">15/07/2026</span>
    <h3><a href="ПОСИЛАННЯ_НА_ДОК_АБО_FB" target="_blank" rel="noopener">Заголовок новини</a></h3>
    <p>Перший абзац тексту новини. Якщо текст довгий — лиши лише перший абзац і додай посилання «Читати далі» нижче.</p>
    <a href="ПОСИЛАННЯ_НА_ДОК_АБО_FB" target="_blank" rel="noopener" class="more">Читати далі</a>
  </div>
</article>
```

**Той самий шаблон (АНГЛІЙСЬКА) — встав у `en.html`** (переклади текст, заголовок «Read more»):

```html
<article class="card">
  <div class="card-media"><img src="img/news-forum-2026.jpg" alt="Short photo description"></div>
  <div class="card-body">
    <span class="badge">15/07/2026</span>
    <h3><a href="LINK_TO_DOC_OR_FB" target="_blank" rel="noopener">News title</a></h3>
    <p>First paragraph of the news text.</p>
    <a href="LINK_TO_DOC_OR_FB" target="_blank" rel="noopener" class="more">Read more</a>
  </div>
</article>
```

Примітки:
- `<span class="badge">` — дата (формат `ДД/ММ/РРРР`) або тег (напр. `#ПРОЄКТ`).
- Заголовок `<h3><a href="...">` — клікабельний; веди на Google Drive документ або пост у Facebook.
- Якщо посилання поки немає — постав `href="#"` і додай пізніше.
- Якщо новина без посилання — прибери `<a>` і лиши просто `<h3>Заголовок</h3>` без рядка «Читати далі».

## 8. Що ще варто знати

- **Не видаляй** файли `CNAME`, `css/style.css`, папку `img/`.
- **Домен і HTTPS** уже налаштовані — DNS-записи `A` ведуть на сервери GitHub Pages
  (`185.199.108.153` тощо), нічого міняти не треба.
- Якщо щось зламалось — кожна зміна збережена в історії git, можна відкотитись:
  ```bash
  git log --oneline         # подивитись історію
  git revert <хеш_комміту>   # відкотити конкретну зміну
  git push origin main
  ```

## 9. Підказка для AI-помічника (Claude / ChatGPT)

Якщо тобі дали цей репозиторій і просять оновити сайт:

1. Це **статичний HTML/CSS** сайт. Жодних фреймворків, npm-білдів — просто редагуй `.html` і `css/style.css`.
2. Сайт **двомовний** — зміни тексту дублюй у UA-файлах (`index.html`, `poslugi.html`) і EN-файлах (`en.html`, `poslugi-en.html`).
3. Дотримуйся наявних **CSS-класів** і кольорів із `:root` — не вигадуй нові стилі без потреби.
4. Зображення клади в `img/`, стискай (~1400px, jpeg), посилання роби **відносними** (`img/...`).
5. Після змін: `git add -A && git commit -m "..." && git push origin main`. Сайт оновиться сам за ~1 хв.
6. Перед видаленням чи масовою заміною — покажи людині, що саме зміниш.
7. Якщо git/gh/Node ще не встановлені — дивись **розділ 4** і встанови їх.
